# Cofre mínimo

Copie esta pasta para onde quiser (por exemplo `~/Jarvis`) e aponte o `vault` do `config.json` para ela.
Funciona como um cofre do Obsidian, mas o Obsidian não é obrigatório: são só arquivos Markdown.

- `VAULT-INDEX.md` e `Active Priorities.md` são opcionais. Sem eles, o Jarvis só usa a própria memória.
- Na primeira conversa, o Jarvis cria `08 - Jarvis/` com a "Memória do Jarvis" e as transcrições do dia.
- As notas que o Jarvis escreve vão para as pastas de `vault_areas` no `config.json`. O padrão é
  `00 - Inbox`, `01 - Projetos`, `02 - Pessoal` e `03 - Recursos`; as pastas são criadas quando precisar.
